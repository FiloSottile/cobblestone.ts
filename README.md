# cobblestone.ts

[`cobblestone-encryption`](https://www.npmjs.com/package/cobblestone-encryption)
is a TypeScript implementation of the chunked (or streaming) encryption scheme
**Cobblestone-128**, as described in
[c2sp.org/chunked-encryption](https://c2sp.org/chunked-encryption).

Cobblestone-128 is based on AES-128-GCM and HKDF-SHA-512, and is designed to
encrypt large messages of up to 4 PiB, allowing authenticated streaming
encryption and decryption, and authenticated random access. The message is
broken up into 16 KiB chunks, each of which is encrypted and authenticated
separately, with protections against reordering and truncation attacks.

This scheme has a fixed overhead of 56 bytes and a marginal overhead of
approximately 0.1%.

It depends only on the [noble](https://paulmillr.com/noble/) cryptography
libraries, and uses the Web Crypto API when available (and a pure JavaScript
AES-GCM otherwise, for example on insecure origins).

It is interoperable with [filippo.io/cobblestone](https://filippo.io/cobblestone)
(Go) and [pyca/cryptography](https://cryptography.io/en/latest/cobblestone/)
(Python), and is tested against the
[Wycheproof test vectors](https://github.com/C2SP/wycheproof/blob/main/doc/c2sp_chunked_encryption.md).

## Installation

This package is `cobblestone-encryption` on npm, and
`jsr:@cobblestone/cobblestone-encryption` on JSR.

It's compiled for ES2023, and compatible with Node.js 22+, Bun, Deno, and all
recent browsers.

```sh
npm install cobblestone-encryption
```

```sh
deno add jsr:@cobblestone/cobblestone-encryption
```

## Usage

`cobblestone-encryption` is a modern ES Module with built-in types.

#### Encrypt and decrypt a message

```ts
import * as cobblestone from "cobblestone-encryption"

const key = cobblestone.generateKey()

const e = new cobblestone.Encrypter(key, "example context")
const ciphertext = await e.encrypt(new TextEncoder().encode("Hello, Cobblestone!"))

const d = new cobblestone.Decrypter(key, "example context")
const out = new TextDecoder().decode(await d.decrypt(ciphertext))
console.log(out)
```

The key must be 16 uniformly random bytes, either generated by `generateKey`
or derived with a KDF (never a password). A single key can be used to encrypt
a practically unlimited number of messages.

The context is optional data bound to the ciphertext: decryption fails
unless the same value is used. It is not secret and it is not part of the
ciphertext, so the decrypting party must know it independently. It can be
used to bind a message to e.g. a filename or a user ID, or for domain
separation (e.g. `"myapp v2 backup encryption"`).

#### Encrypt and decrypt using the Streams API

`EncryptionStream` and `DecryptionStream` are [transform streams][] like
`CompressionStream`, to be used with `pipeThrough`. This can be useful for
encrypting or decrypting large files, requests, or responses on the fly. Each
instance processes a single message.

[transform streams]: https://developer.mozilla.org/en-US/docs/Web/API/TransformStream

```ts
import { EncryptionStream, DecryptionStream, generateKey, ciphertextSize } from "cobblestone-encryption"

const key = generateKey()
const file = new File([new TextEncoder().encode("Hello, Cobblestone!")], "hello.txt")

const encryptedStream = file.stream().pipeThrough(new EncryptionStream(key, "example context"))
console.log(ciphertextSize(file.size))

const decryptedStream = encryptedStream.pipeThrough(new DecryptionStream(key, "example context"))
console.log(await new Response(decryptedStream).text())
```

The decrypted stream errors if the message was encrypted with a different key
or context, or was modified, truncated, or extended. Each chunk of plaintext
is authenticated before it's produced, but the message could still turn out
to be truncated, so an application that acts on the plaintext before the
stream ends must be prepared to discard its work.

`ciphertextSize` and `plaintextSize` compute the exact size of the output
from the size of the input, for example to set a `Content-Length` header.

#### Random access decryption

Messages can also be decrypted selectively, without processing the whole
ciphertext. `Decrypter.decryptBlob` takes a [Blob][] (such as a [File][]), or
any object with its `size` and `slice` methods (for example one backed by
HTTP Range requests), and returns a lazy Blob-like `DecryptedBlob`. The
message size is authenticated up front by decrypting the final chunk, and the
other chunks are decrypted as they are read.

```ts
import { Encrypter, Decrypter, generateKey } from "cobblestone-encryption"

const key = generateKey()

const e = new Encrypter(key)
const ciphertext = await e.encrypt(new TextEncoder().encode("Hello, Cobblestone!"))

const d = new Decrypter(key)
const plaintext = await d.decryptBlob(new Blob([ciphertext]))
console.log(plaintext.size)
console.log(new TextDecoder().decode(await plaintext.slice(7, 18).bytes()))
console.log(await new Response(plaintext.slice(-1).stream()).text())
```

`slice` has the same semantics as [`Blob.slice`][]: it returns a view without
reading anything, negative indexes count from the end, and out of range indexes
are clamped.

[Blob]: https://developer.mozilla.org/en-US/docs/Web/API/Blob
[File]: https://developer.mozilla.org/en-US/docs/Web/API/File
[`Blob.slice`]: https://developer.mozilla.org/en-US/docs/Web/API/Blob/slice

### Browser usage

`cobblestone-encryption` is compatible with modern bundlers such as
[esbuild](https://esbuild.github.io/).

To produce a classic library file that sets `cobblestone` as a global variable,
you can run

```sh
cd "$(mktemp -d)" && npm init -y && npm install esbuild cobblestone-encryption
npx esbuild --target=es2023 --bundle --minify --outfile=cobblestone.js --global-name=cobblestone cobblestone-encryption
```

or download a pre-built one from the [Releases page](https://github.com/FiloSottile/cobblestone.ts/releases).

Then, you can use it like this

```html
<script src="cobblestone.js"></script>
<script>
(async () => {
    const key = cobblestone.generateKey()

    const e = new cobblestone.Encrypter(key, "example context")
    const ciphertext = await e.encrypt(new TextEncoder().encode("Hello, Cobblestone!"))

    const d = new cobblestone.Decrypter(key, "example context")
    const out = new TextDecoder().decode(await d.decrypt(ciphertext))
    console.log(out)
})()
</script>
```

## Testing

```sh
npm run build
npm run lint
npm run test        # Node.js, Firefox, and Chrome
npm run test:short  # Node.js only
npm run test:slow   # Node.js only, including slow tests
```

The test suite includes the [Wycheproof test vectors](https://github.com/C2SP/wycheproof/blob/main/doc/c2sp_chunked_encryption.md)
and round-trip tests against filippo.io/cobblestone (if `go` is available)
and pyca/cryptography (if `python3`, or the interpreter in `$PYTHON`, can
import `cryptography.cobblestone`).

```sh
npm run test:interop
```
